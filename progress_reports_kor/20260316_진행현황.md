# 20260316 진행 보고서

## WhisperPair - CVE-2025-36911

이 취약점은 Google Fast Pair를 구현한 기기를 대상으로 합니다. 특정 기기가 Google Fast Pair를 사용하는지 여부는 `bluetootlkit pair {target}`을 실행하여 UUID `0xFE2C`가 출력되는지 확인하면 알 수 있습니다 (Fast Pair characteristics의 전체 128-bit UUID는 `0000xxxx-0000-1000-8000-00805F9B34FB` 형식을 따릅니다).

Google Fast Pair 사양에 따르면, 기기가 명시적으로 pairing mode로 설정되지 않은 경우 pairing 요청을 무시해야 합니다. 그러나 일부 제조사에서는 이 검사를 구현하지 않았습니다. 이로 인해 공격자가 피해자의 accessory에 강제로 pairing하여 오디오를 탈취하거나 기기를 추적할 수 있습니다.

WhisperPair 검사를 BlueToolkit에 구현하기 위해 [이 취약점에 대한 오픈소스 테스트 코드](https://github.com/Cedric-Martz/CVE-2025-36911_scan)를 `/usr/share/BlueToolkit/modules/tools/custom_exploits/bluekit_whisper_check.py`에 가져왔습니다. 이후 `/usr/share/BlueToolkit/exploits`에 새로운 YAML 파일을 추가하여 이 검사를 참조하도록 했습니다:

```yaml
author: yso
bt_type: BREDR
bt_version_max: 5.4
bt_version_min: 4.0
command: 'python3 bluekit_whisperpair_check.py '
directory:
  change: true
  directory: modules/tools/custom_exploits
hardware: default
log_pull:
  from_directory: false
  in_command: false
mass_testing: true
max_timeout: 30
name: whisperpair_cve_2025_36911
parameters:
- help: Target MAC address
  is_target_param: true
  name: --target
  name_required: true
  parameter_connector: ' '
  required: true
  type: str
type: PoC
```

BLE 기기에서 테스트하려면 `bt_type` 속성을 `BLE`로 변경하면 됩니다. BlueToolkit에서 PoC 코드를 성공적으로 실행한 결과, 이전에 테스트했던 모든 기기(Galaxy 10+ 5G, Galaxy 10 5G, Galaxy S7, iPhone 13 Pro, soundcore Motion X600)가 해당되는 것으로 확인되었습니다.
