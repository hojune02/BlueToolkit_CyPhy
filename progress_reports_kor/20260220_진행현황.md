# 20260220 진행현황

## `net/ipx.h` 관련 Braktooth 셋업 에러
Ubuntu 22.04로 다운그레이드 후 커널 버전도 5.15로 바꾸어 보았지만, ESP32 셋업 시 `net/ipx.h`를 찾을 수 없어 나타나는 오류가 지속했습니다. 이를 완전히 해결하려면 커널 버전을 더 낮추어야 하는데, 그럴 경우 BlueToolkit이 잘 실행될지에 대한 여부를 판단해야할 필요가 있습니다.

`net/ipx.h`는 Braktooth의 다음 커맨드를 실행하기 위해서 필요한 파일입니다:
```bash
sudo bin/wifi_ap_fuzzer # Start fuzzer without graphical interface
```
위의 커맨드를 BlueToolkit에서는 사용하지 않는 것에 착안하여 아예 해당 툴 설정을 배제하고 다시 설치를 실행한 결과, 오류 없이 완료할 수 있었습니다.

## ESP32-WROVER-KIT의 필요성 확인

Braktooth는 ESP32-WROVER-KIT 기기를 사용하기 때문에, 연결 시 `/dev/ttyUSB0`와 `/dev/ttyUSB1`이 우분투 머신에 동시에 감지됩니다. Braktooth의 README에서 필요한 포트가 `/dev/ttyUSB1`이라고 설명이 되어있는데, 우리가 지금 가지고 있는 ESP32 기기 (ESP32-WROOM-32E)는 우분투 연결 시 `/dev/ttyUSB0`만 인식되어 Braktooth 실행이 되지 않습니다. 

## 결론

따라서 현재 문제 해결이 필요한 사항은 다음과 같습니다:

- **ESP32-WROVER-KIT 구하기**. 현재 연구실에 있는 ESP32-WROOM-32E는 serial communication이 불가능하여 Braktooth에 사용할 수 없습니다. 깃헙 이슈 부분에 ESP32와의 호환성을 다룬 Question을 찾았는데, 현재 있는 ESP 기기 자체만으로 해결할 수 있는 문제가 아님을 알 수 있었습니다. 
([링크](https://github.com/Matheus-Garbelini/braktooth_esp32_bluetooth_classic_attacks/issues/2#issuecomment-1039289299)) 따라서 ESP32-WROVER-KIT을 구하는 것이 합리적인 해결책으로 보입니다. 현재 단종이 되었지만 중고 부품을 구매하는 것이 최선책으로 생각되고, 차선책으로는 이 [깃헙 Question](https://github.com/Matheus-Garbelini/braktooth_esp32_bluetooth_classic_attacks/issues/55)에서 언급된 [ESP32-ETHERNET-KIT-VE](https://www.digikey.kr/ko/products/detail/espressif-systems/ESP32-ETHERNET-KIT-VE/13414972)를 구매해보는 것이 있습니다.

- (선택) `net/ipx.h`가 존재하는 커널로 다운그레이드하여 BlueToolkit 내부의 Braktooth 다시 셋업하기. 이 부분은 BlueToolkit이 `sudo bin/wifi_ap_fuzzer` 기능을 사용하지 않기 때문에 중요도가 높지 않습니다.
