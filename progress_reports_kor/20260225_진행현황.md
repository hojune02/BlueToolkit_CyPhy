# 20260225 진행현황

ESP32 KIT가 도착하기 전까지는 Braktooth에 대한 vulnerability testing을 진행할 수 없습니다.

---

### btmon_feature_extractor는 이제 LMP feature 추출을 위해 `hcitool info`를 사용함

`hcitool info`를 실행하면 LMP features는 bitmask 형태로 표현됩니다. reconnaissance vulnerabilities 확인을 위해, 프로그램은 아래 feature들이 존재하는지 검사합니다.

* LE Supported (Controller): Page 0, 4th byte, 6th bit
* LE Supported (Host): Page 1, 0th byte, 1st bit
* Simultaneous LE and BR/EDR to Same Device Capable (Controller): Page 0, 6th byte, 1st bit
* Simultaneous LE and BR/EDR to Same Device Capable (Host): Page 1, 0th byte, 2nd bit
* Secure Simple Pairing (Controller Support): Page 0, 6th byte, 3rd bit
* Secure Simple Pairing (Host Support): Page 1, 0th byte, 0th bit
* Secure Connections (Controller Support): Page 2, 1st byte, 0th bit
* Secure Connections (Host Support): Page 1, 0th byte, 3rd bit

해당 bit 위치는 Bluetooth Core Specification과 `/usr/src/linux-headers-6.8.0-100-generic/net/bluetooth/hci.h` (Ubuntu 22.04 6.8.0-100-generic 기준)를 통해 확인하였습니다.

---

### ESP32-ETHERNET-KIT-VE (Braktooth) 통합 준비

`requirements2.sh` 실행 시 Linux kernel >= 5.15 환경에서 `net/ipx.h`가 존재하지 않아 실패하였습니다. Braktooth는 해당 파일을 Wi-Fi AP Fuzzer에서 요구합니다.

그러나 BlueToolkit은 `bin/bt_exploiter` binary만 사용하므로, testing 목적상 해당 구성 요소는 필요하지 않습니다. 따라서 installation script 내 관련 부분인
`cd src/drivers/wifi/rtl8812au && make -j4`는 주석 처리하였습니다.

현재까지 Ubuntu machine 측에서 필요한 모든 setup은 완료된 상태입니다.

이제 ESP32 KIT가 도착하면 아래 명령어를 실행하여 setup을 진행하면 됩니다:

```bash
source /usr/share/BlueToolkit/.venv/bin/activate

cd /usr/share/BlueToolkit/modules/tools/braktooth/release

sudo python3 firmware.py flash /dev/ttyUSB1
```
